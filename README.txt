Darrene & Shehara Wedding Invitation - Mobile Friendly Version

Files in this package:
- index.html
- styles.css
- script.js

How to use:
1. Replace your existing index.html, styles.css and script.js with these files.
2. Keep your existing assets folder unchanged in the same location.
3. Keep 1.mp4 in the same location as index.html, as in your current setup.

Mobile improvements include:
- Responsive hero typography and date layout
- Better spacing for small phones
- Stacked couple/event/family/RSVP layouts
- Mobile-friendly countdown and calendar buttons
- Larger touch targets
- iPhone form zoom prevention
- Safe-area support for notched phones
- Landscape-phone handling

Your RSVP endpoint and existing JavaScript functionality are preserved.
